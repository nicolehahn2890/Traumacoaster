# Recherche 3: Gesten-Bedienung auf Mobile (Grundlage für das Bedienkonzept)

## Plattform-Regeln (Apple HIG, Material, Barrierefreiheit)
- Mindestgröße für Tipp-Ziele: 44 × 44 pt (Apple), 48 dp (Material). Finger decken 30–50 px ab, Bezier-Handles brauchen deshalb große unsichtbare Trefferflächen (mindestens 44 pt), auch wenn sie klein gezeichnet werden.
- Standardgesten nicht umdeuten: Tippen = auswählen, Ziehen = bewegen/scrollen, Pinch = Zoom, Doppeltipp = Zoom/Reset, Langdruck = mehr Infos, Schütteln = Undo (muss abschaltbar sein).
- Keine Aktion nur über Geste anbieten: Es muss immer auch einen sichtbaren Button geben (Undo, Play, Zurück).
- Bildschirmkanten freihalten (System-Gesten für Home, Control Center).
- Mehrfinger-Gesten sind für Spiele und Zeichen-Apps akzeptiert, für normale Apps nicht.

## Zeichen-Apps als Vorbild (Procreate, Freeform, Illustrator, Toonsquid, Glyphr)
- Ein Finger zeichnet, zwei Finger navigieren (Pan/Zoom), Zwei-Finger-Tipp = Undo, Drei-Finger-Tipp = Redo. Zeichnen und Navigation sind strikt getrennt.
- Strich sofort anzeigen, dann glätten (Streamline): Rohe Touch-Punkte sind verrauscht; Glätten plus Vereinfachung ist Pflicht.
- Illustrator-Bleistift: Neuer Strich nahe am Pfad ersetzt den überzeichneten Abschnitt. Genau dieses Verhalten ist im Prompt gefordert.
- Bezier-Modell statt Punktlisten: Gesten als Bezier-Kurven speichern, damit sie editierbar bleiben (SketchADoodle-Paper).
- QuickShape (Procreate): Strich halten am Ende → Form wird zu perfektem Kreis/Linie. Übertragbar: Strich am Ende halten → Looping wird zu sauberer Klothoide.

## Konsequenzen für Trauma Coaster
1. Ein Finger: zeichnen / Handle ziehen / Chip tippen. Zwei Finger: Pan, Pinch-Zoom, Zwei-Finger-Tipp Undo.
2. Jede Geste hat eine Button-Alternative: Undo-Button, Play-Button, Zurück-Button, Zoom-Reset per Doppeltipp auf leere Fläche.
3. Handles: gezeichnet 14 px, Trefferfläche 48 px. Handles erscheinen nur am angetippten Knoten, sonst bleibt der Bildschirm sauber.
4. Strich wird live gezeigt, nach dem Loslassen in 150 ms weich in die geglättete Bahn überführt (Morph), damit der Spieler sieht, was passiert.
5. Chips (Spur ↑/↓, Start-Typ) sitzen direkt an der Bahn, nicht in Menüs.
6. Kein Modus-Umschalter: Die Zeichenfläche weiß aus dem Kontext (leer, auf Bahn, auf Handle, auf Chip), was gemeint ist.
