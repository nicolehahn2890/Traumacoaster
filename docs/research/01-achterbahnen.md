# Recherche 1: Achterbahnen, Elemente, Rekorde, Physikgrenzen

Stand: Oktober 2026. Quellen am Ende. Die Elementbeschreibungen fassen Coasterpedia/CoasterForce zusammen; Rekorde stammen aus Presse und Herstellerangaben und sind als Orientierung gedacht, nicht als amtliche Werte.

## 1. Element-Katalog (Grundlage für den Element-Katalog im GDD)

### Antrieb und Start
| Element | Beschreibung | Übertragung ins Spiel |
|---|---|---|
| Kettenzug (Chain Lift) | Kette zieht den Zug langsam den Lifthügel hoch; klassischer Start mit Klack-Klack-Sound | Start-Chip „Kettenzug“: Bahn darf von der Station aus bergauf gehen |
| Kabellift / Vertikallift | Schneller Lift per Seil oder senkrecht | Spätere Lift-Variante, schneller und steiler |
| LSM/LIM-Launch | Linearmotoren beschleunigen den Zug auf ebener Strecke, mehrere Launches hintereinander möglich (Falcon's Flight: drei LSM-Launches) | Start-Chip „Launch“, Element „Booster“ auf gerader Strecke |
| Hydraulik-Launch | Extrem starke Beschleunigung (Formula Rossa: 0 auf 240 km/h in ~5 s) | „Hydro-Launch“ als stärkste Launch-Stufe |
| Reifenantrieb | Reibräder schieben den Zug, auch rückwärts | Booster, Hilfsantrieb in Stationen |
| Rückwärts-Launch / Swing Launch | Zug pendelt mehrfach durch die Station, baut Tempo auf | Spätes Element „Pendel-Launch“ |

### Inversionen (Überschläge)
| Element | Beschreibung |
|---|---|
| Vertikaler Looping | Klassischer tropfenförmiger Kreis (Klothoide), keine reine Kreisform wegen der g-Kräfte |
| Immelmann | Halber Looping, dann halbe Rolle; Zug verlässt die Figur seitlich in Gegenrichtung |
| Dive Loop | Umgekehrter Immelmann: erst halbe Rolle, dann halber Looping nach unten |
| Cobra Roll | Doppelte Inversion: halber Looping, zwei gespiegelte halbe Korkenzieher, halber Looping; Zug fährt in Gegenrichtung zurück |
| Batwing / Bowtie | Doppelinversion aus halbem Korkenzieher + halbem Looping und Umkehrung |
| Korkenzieher (Corkscrew) | Gestreckter, schräg liegender Looping |
| Zero-G-Roll | Heartline-Rolle auf dem Scheitel eines Hügels, Fahrgäste sind kurz schwerelos |
| Heartline-Roll / Inline-Twist / Barrel Roll | 360°-Drehung um die Längsachse etwa auf Brusthöhe der Fahrgäste (im Spiel: „Schleife“ über das Roll-Handle) |
| Cutback | Wie Korkenzieher, Ausfahrt aber in Gegenrichtung |
| Pretzel Loop | Brezelförmiger Looping (Flying Coaster) |
| Norwegian Loop | Dive Loop direkt gefolgt von Immelmann |
| Sea Serpent / Roll Over | Zwei Inversionen hintereinander, Zug fährt gleiche Richtung weiter |
| Inclined Loop | Schräg gelegter Looping |

### Airtime und Hügel
| Element | Beschreibung |
|---|---|
| Airtime-Hügel / Camelback | Parabolischer Hügel, Fahrgäste heben ab (negative g) |
| Bunny Hops | Mehrere kleine, schnelle Airtime-Hügel |
| Speed Hill | Flacher, schneller Hügel mit starker Ejector-Airtime |
| Top Hat | Steiler Auf- und Abstieg mit 90°-Kurve oben (Launch-Coaster) |
| Stengel Dive | Überhöhte Kurve, die auf der Außenseite in einen Hügel kippt |
| Trick Track | Wellenförmige Verschränkung, Wagen kippt links/rechts |
| Pre-Drop | Kleiner Abfall vor dem Haupt-Drop, entspannt die Kette |
| Beyond-Vertical-Drop | Drop steiler als 90° |

### Kurven
| Element | Beschreibung |
|---|---|
| Überhöhte Kurve (Banked Turn) | Geneigte Kurve, Querkraft wird in Sitzdruck umgewandelt |
| Overbanked Turn | Kurve über 90° Neigung, fast Inversion |
| Helix | Spiralförmige Kurve, mehrere Umdrehungen |
| Hammerhead | 180°-Kurve, überhöht, mit Höhenänderung |
| Horseshoe | 180°-Kurve als Hufeisen |
| S-Kurve / Slalom | Schnelle Richtungswechsel |
| Turnaround | 180°-Wende am Ende einer Out-and-Back-Bahn |

### Strecken-Sonderelemente
| Element | Beschreibung |
|---|---|
| Tunnel | Unterirdischer oder verbauter Abschnitt, verstärkt Tempoeindruck |
| Splashdown | Flossen tauchen in Wasser, Fontäne |
| Head Chopper | Scheinbar zu niedrige Balken/Stützen |
| Drop Track / Fall-Segment | Schienenstück fällt senkrecht nach unten |
| Switch Track / Tilt | Weiche oder Kippschiene |
| Dark-Ride-Abschnitt | Szenen in Gebäuden mit Lichteffekten |
| Blockbremse / Trimbremse | Zwischenbremse, Sicherheitsabschnitt |
| Rückwärtsfahrt | Zug fährt Teil der Strecke rückwärts (Boomerang) |
| Interaktive Strecke | Kreuzungen, Fast-Berührungen zweier Züge (Dueling Coaster) |

### Bahntypen (Schienen- und Streben-Stile)
Holz (klassische Holzkonstruktion, viele Streben), Hybrid (Holzgerüst mit Stahlschiene, z. B. RMC), Stahl (Rohrschiene, filigrane Stützen), Minenzug (Mine Train, niedrige Stahlbahn im Felsen), Wilde Maus, Bobbahn, Hänge-/Inverted, Flying, Wing, Dive (Senkrecht-Drop mit Halt), Hyper/Giga/Strata (Höhenklassen: über 60 m, 90 m, 120 m), Spinning, Family/Kinder, Wasserachterbahn, Single-Rail, Powered Coaster.

## 2. Rekorde (Orientierung, Stand Anfang 2026)
- Falcon's Flight (Six Flags Qiddiya City, Intamin, eröffnet 31.12.2025): schnellste (~250 km/h), höchste (~160–195 m je nach Messbasis) und längste (~4,2 km) Achterbahn, drei LSM-Launches.
- Formula Rossa (Ferrari World): schnellster Launch (0 auf 240 km/h in ca. 4,9 s, Hydraulik).
- The Smiler (Alton Towers): 14 Inversionen, Rekord.
- Tormenta Rampaging Run (Six Flags Over Texas, geplant): 179 ft Looping, größter Looping der Welt, sechs Rekorde angekündigt.
- Bakunawa (Six Flags Great Adventure, 2027): höchste und schnellste Spinning-Launch-Bahn.
- Tatsu (Six Flags Magic Mountain): höchste und schnellste Flying Coaster.

## 3. Physikgrenzen (für das Fahrmodell)
- Positive vertikale g: moderne Bahnen erreichen 4–5 g kurzzeitig; 5–6 g gelten als absolute Obergrenze (ASTM F2291 begrenzt nach Einwirkdauer).
- Negative vertikale g (Airtime): −0,5 bis −1,5 g üblich bei „Ejector-Airtime“; Hersteller wie GCI legen Holzzüge auf max. 0 g aus; RCT-Faustregel: unter −2 g crasht die Bahn.
- Seitliche g: ±1,5 g dauerhaft, bis ~3 g sehr kurz (< 0,2 s); darüber gelten Kräfte als „Kollision“. Holzbahnen vertragen weniger seitliche g als Stahlbahnen.
- Loopings sind Klothoiden: oben kleiner Radius (genug Andruck), unten großer Radius (weniger g).
- Konsequenz für Trauma Coaster: Entgleisen wird über seitliche g (Kurvenradius vs. Tempo, abhängig vom Schienentyp) und Rauswurf der Fahrgäste über negative vertikale g (echte Physik) modelliert. Oben im Looping muss der Zug mindestens v = sqrt(g·r) haben, sonst fällt er heraus.
